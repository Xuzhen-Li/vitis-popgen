# 基于 ARG 的群体遗传

现有目录已在第 4 节列出 tsinfer、tsdate、Relate、SINGER 和 tskit，第 16 节有“用 ARG 给葡萄驯化定年”的想法。本章补充 2026-11-15 CST 实际打开的方法论文和 README。本次追加没有推断葡萄的 ARG。

Kelleher 等（2019，全文）的 tsinfer 可在很大样本上推断全基因组谱系，文中应用到 1000 Genomes、SGDP 和 UK Biobank。Speidel 等（2019，全文）的 Relate 可处理超过 1 万条序列，同时估计枝长、突变年龄和历史有效种群大小，文中应用到 26 个人类群体。Wohns 等（2022，全文，doi:10.1126/science.abi8264）用现代和古代人类基因组做统一谱系，摘要写古代样本用来约束并给关系定年；tsdate 的 README 把这篇当作原始算法文献。Deng、Nielsen 和 Song（2025，全文）的 SINGER 从后验分布抽样 ARG，以量化不确定性，文中应用到 1000 Genomes 的英国和非洲个体。Brandt 等（2024，全文）是关于 ARG 的综述。

若要在葡萄上按第 16 节的想法做，方法级路线仍是：公开、按本仓库现有规则去无性系（直播主分支 commit `eb29b98c…` 的 `docs/WORKFLOW.md` 第 3 步：KING kinship 大于 0.354 视为同一克隆或重复，对应 KING 手册的 duplicate/MZ 级别；一级亲缘 0.177–0.354 不当克隆去掉。手册已打开；Manichaikul 等 2010 摘要里没有 0.354，正文未打开，标 [待确认]）、极化过的面板；用 tsinfer（或按论文适用条件选用 Relate / SINGER）推断；需要年龄时用 tsdate，默认 variational_gamma 算法应引 Pope 等 2026。Relate / SINGER 需要已分相数据、遗传图谱、突变率和祖先态；官方示例参数都是人类的，不能照搬。葡萄遗传图谱以及 μ、g 仍为 [待确认]。把现存无性系的样本日期写成有性起源时间，是模型假设，不是工具文档里给古 DNA 用的样本年龄，敏感性需要另做。现存无性系仍可能带有自有性起源以来积累的体细胞突变（本仓库推理，未引文献，[待确认]）。以上论文都没有分析 Vitis。把它们在人类数据上的精度直接当成无性繁殖多年生植物上的结论，属于外推，标为 [待确认]。Pope 等 2026 的完整 DOI 为 10.64898/2026.01.07.698223（在 v4 修订中打开了摘要，未下载全文）。
