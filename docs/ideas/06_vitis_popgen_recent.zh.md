# 近年葡萄群体基因组研究

本章记录本组教学章节打开的葡萄重测序和泛基因组论文。其中多篇已在目录中（Dong 2023、Magris 2021、Xiao 2023、Freitas 2021、Liang 2019、Zhou 2017、Liu 2024、Guo 2025）。有两篇 2026 年论文此前未列入。重点不是选定一个驯化故事，而是把已发表的说法并列保存。

Dong 等（2023，仅摘要）分析全球 3,525 份栽培和野生材料，写驯化约在 11,000 年前同时发生在西亚和 Caucasus，从而得到鲜食和酿酒葡萄；摘要没有写 respectively，下一句还写西亚驯化的那一支后来参与了西欧酿酒葡萄祖源，因此不要画成“西亚=鲜食、高加索=酿酒”的一一对应。该文的 μ、g 标为 [待确认]。Magris 等（2021，全文）分析 204 份 Vitis vinifera 基因组，写所有分析都支持一次发生在西亚的驯化，随后有来自欧洲野生群体的大量渗入。Xiao 等（2023，全文）分析 345 份材料，摘要支持一次驯化，并写近约 2,000 年来的基因流“尤其是从欧洲野生进入酿酒葡萄”；“进入酿酒、而不是鲜食”出自 Significance，不是摘要，这里弱化。打开的 Xiao 全文检索 Western Asia 为 0 次。勘误 doi:10.1073/pnas.2317674120（本修订打开全文，PMC10756202，NCBI efetch XML 11,216 字节，2026-11-15 CST）写明 345 份中有 17 份（5%）被鉴定有误而剔除，群体遗传分析用的是 328 份，并替换了 Fig. 4，把 SI 表 n=148 改为 n=154。摘要仍写 345 份。Freitas 等（2021，全文）支持一次中心驯化后再与当地野生基因型杂交，最强信号出现在一部分伊比利亚酿酒品种的大片段渗入，并写成适应性渗入。这些摘要在“一次还是两次驯化”上并不一致。本仓库不裁决这一分歧。

Zhou 等（2017，全文）估计他们的野生与栽培样本大约在 22,000 年前分化，此后栽培谱系的有效种群大小持续下降。这是 sylvestris 与酿酒或鲜食葡萄的 MSMC 交叉溯祖（Fig. 2B），换算用了 g = 3 年和 μ = 2.5×10⁻⁹ /bp/yr；同一篇里 n = 4 的两次运行是 vinifera 的 Ne 分析（Fig. 2A）。交叉溯祖用的样本组成标为 [待确认]（SI Appendix Table S1 未打开）。同一篇的 SMC++ 给出约 30 kya，鲜食与酿酒约 2.6 kya 分化；Significance 还有 “22,000-y population decline prior to domestication” 原句。各研究的年代建立在不同的模型和（除非另行核对）不同的 μ、g 上，不能直接比大小。Dong 和亚美尼亚文的 μ、g 标为 [待确认]。负荷结果见 05_pgs_and_load.md。Liang 等（2019，全文）报道 472 份材料、覆盖现存约 60 个种中的 48 个，并写栽培葡萄最近有效种群大小有剧烈扩张和收缩，黑海周围品种有独特的人口史。

Liu 2024 和 Guo 2025 的摘要见 04_graph_sv_popgen.md。Wang 等（2026，PNAS，全文）分析 639 份、代表 48 个种的重测序数据，对 19 个种做群体遗传，并写渗入约占平均 Vitis 基因组的 14%，与种间地理分布有关，高度混合的个体更常出现在生态位边缘。Nikoghosyan 等（2026，全文）重新分析此前全球收集中的 164 份亚美尼亚栽培和野生材料：野生与栽培分组清楚，栽培基因库有三个祖源成分，沿亚美尼亚由西向东的地理梯度分布；野生与栽培谱系约在 18,500 年前开始分开，约 4,000 年前在栽培下分化加强。这些年代是该研究的估计，不替代 Dong 或 Zhou；该文换算用的 μ、g 标为 [待确认]。
