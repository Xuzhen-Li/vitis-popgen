# vitis-popgen

English | [中文](README.zh.md)

This repository is currently a placeholder (README only, no code yet) for *Vitis* population structure, gene flow, and domestication analyses on public or published data.

## This is not

* Not the 167K analysis product (FASTQ to panel VCF to ancestry reports): [grapeancestry](https://github.com/Xuzhen-Li/grapeancestry)
* Not theory notes (one paper, one folder): [genomics-theory-mining](https://github.com/Xuzhen-Li/genomics-theory-mining)
* Not chip design: [grapevine-chip](https://github.com/Xuzhen-Li/grapevine-chip)
* Not a place for unpublished genotype matrices

## What will land later

Methods, scripts, and notes only.

- Structure, gene-flow, and domestication recipes on public or published data
- Clone-aware PCA / ADMIXTURE notes
- Pointers to public datasets when a script needs them

No unpublished genotypes, private coordinates, or sample-level matrices.
