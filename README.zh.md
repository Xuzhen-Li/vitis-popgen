# vitis-popgen

[English](README.md) | 中文

本仓库目前仅为占位符（仅包含 README，暂无代码），用于存放基于公开或已发表数据的 *Vitis* 群体结构、基因流和驯化分析。

## 本仓库不包含

* 不是 167K 分析产品（从 FASTQ 到 panel VCF 再到祖源报告）：[grapeancestry](https://github.com/Xuzhen-Li/grapeancestry)
* 不是理论笔记（一篇论文，一个文件夹）：[genomics-theory-mining](https://github.com/Xuzhen-Li/genomics-theory-mining)
* 不是芯片设计：[grapevine-chip](https://github.com/Xuzhen-Li/grapevine-chip)
* 不用于存放未发表的基因型矩阵

## 后续更新内容

仅包含方法、脚本和笔记。

* 基于公开或已发表数据的群体结构、基因流和驯化分析流程
* 考虑克隆的 PCA / ADMIXTURE 笔记
* 脚本所需的公开数据集链接

没有未发表的基因型、私有坐标或样本级别的矩阵。
